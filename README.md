# Advanced Assembly Machines: Improved

Five tiers of compact 3×3 assemblers, with planet-themed graphics and native production animations.

**Factorio 2.1 · Version 1.1.3**

- Crafting speeds: 20, 40, 80, 160 and 320.
- Configurable module slots and optional Space Age productivity.
- Planetary production milestones unlock the higher tiers; base-game recipes are included.

[Recipes, progression and existing-save layout](docs/RECIPES.md).

## Installation

Disable the original Advanced Assembly Machines mods before enabling this fork. Existing machines keep their positions and names. When switching from the old 5×5 footprint, move adjacent inserters, pipes and loaders one tile closer.
